# AmpElectric

A concept website for an electrical engineering business, built to practice responsive design and a service-booking flow. Customers can browse electrical handyman services and book online.

**Live site:** [ampelectric.com.ng](https://ampelectric.com.ng/)

## Features
- Fully responsive layout for mobile, tablet, and desktop
- Service listings for electrical handyman work
- Online booking flow

## Built With
HTML5 · CSS3 · JavaScript · Bootstrap 5

## What I Practiced
- Turning a design into a clean, responsive layout
- Structuring a booking flow that's simple for customers to follow

## Note
This is a concept project built for portfolio purposes.
